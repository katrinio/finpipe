# Workflows

### generate_invoice_and_send

Основной пользовательский сценарий.

- Генерирует инвойс за текущий период.
- Создаёт PDF и DOCX версии документа.
- Отправляет готовые файлы в Telegram.

---

### process_bank_request

Основной банковский сценарий.

- Проверяет новые банковские письма.
- Загружает PDF-вложения.
- Заполняет банковские документы.
- Отправляет результат в Telegram.

---

### prepare_bank_pdf

Совместимый alias для process_bank_request.

Сохранён для старых точек входа и обратной совместимости.

---

### send_daily_healthcheck

Ежедневная проверка состояния системы.

- Собирает результаты healthcheck.
- Формирует краткий отчёт.
- Отправляет статус в Telegram.

Предназначен для запуска по расписанию.

# Tasks

### generate_invoice

Генерация инвойса из шаблонов.

- Формирует данные за период.
- Создаёт PDF и DOCX документы.
- Сохраняет запись в истории инвойсов.

---

### generate_transfer_request

Генерация transfer request.

- Заполняет шаблон документа.
- Создаёт PDF.
- При наличии подписи автоматически добавляет её в документ.

---

### fill_bank_pdf

Заполнение банковского PDF.

- Подставляет сумму и реквизиты.
- Добавляет дату инвойса.
- При необходимости добавляет подпись.

---

### fetch_bank_email

Получение банковских писем.

- Находит новое письмо банка.
- Загружает вложения.
- Помечает письмо как обработанное.

---

### clear_processed_history

Очистка истории обработанных банковских писем.

Используется для повторной обработки писем и отладки.
